# 🤖 LR.AI - Business Chatbot Assistant

**LR.AI** is a customizable chatbot solution designed for businesses of all sizes. It handles FAQs, generates leads, answers client queries, and supports voice, multiple languages, and smart UI features.

### 🌟 Features
- 💬 Natural conversation powered by LLaMA-3 via Groq API
- 🎤 Voice input and output
- 🌐 Multi-language support
- 🌙 Dark mode toggle
- 📋 Preloaded questions for instant engagement
- 🔄 Conversation reset button
- 📞 Contact form integration (email or analytics)
- 📱 Mobile-responsive design
- 🧠 Typing animation for natural feel
- ⚡ Easy to embed on any website
